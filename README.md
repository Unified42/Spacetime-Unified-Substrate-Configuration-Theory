This archive publishes the Theory of Spacetime Unified Substrate Configuration. It is a unified cosmological model grounded in continuum phase transitions. Without introducing dark matter or dark energy, the model adopts a single theoretical framework to coherently interpret physical phenomena at diverse scales. A number of validations on galactic dynamics and cosmological observations have been accomplished. This archive is created merely to confirm the first publication of this original research.
